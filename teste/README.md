
# Agenda

## Como executar

### Database
```rake db:create```    
```rake db:migrate```   
```rake db:seed```   

### Build
```docker compose up --build```   

### Acessar docker 'web' 
```docker compose exec web bash```    

## Abrir no navegador
* ```http://localhost:3000/```
* E-mail default: ```admin@admin.com```
